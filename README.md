## What It Does

- Tracks a 28-day SEO, citations, backlinks, GBP, social profiles, partner outreach, blog and monthly recurring task plan
- Interactive dashboard with progress cards, week-by-week progress bars, and filters
- Checkboxes, completion dates, and status dropdowns on every task
- Citation directory tracker with submission and verification status
- Local partner outreach table with contact tracking and backlink status
- Blog tracker with target keywords and publish workflow
- Google Search Console and Google Business Profile checklists
- One-click copy buttons for business NAP, 12 GBP services, email outreach templates, and the full 28-day plan
- Export/Import progress as JSON
- Dark mode toggle & print-ready layout
- Mobile-friendly responsive design
- All progress automatically saved in `localStorage`

## How to Run Locally

1. Open `index.html` in any browser or launch via local server
2. No dependencies or build steps required

## How to Deploy to GitHub Pages

1. Push all files to the `main` branch of your GitHub repository
2. Go to **Settings > Pages**
3. Under **Source**, select `Deploy from a branch`
4. Select `main` branch and `/ (root)` folder
5. Click **Save**
6. The site will be live at `https://yourusername.github.io/repo-name/`

## How Progress Is Saved

All progress is saved in your browser using `localStorage` under the key `jimmys_seo_state`.

- Progress persists across page reloads
- You can export progress as a JSON file and import it on any device
- Completely client-side; no backend database required
